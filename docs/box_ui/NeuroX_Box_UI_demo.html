The screen is drawn in real 320 × 240 ILI9341 pixels (shown at 2×), so each layout maps straight to TFT_eSPI calls. The labels along its bottom edge sit right above the LEFT, NEW and OK buttons, as they do on the printed lid. The flow follows the firmware: it calibrates at power-on, starts locked, unlocks after 3 s of eyes firmly closed, locks again after 3 s idle, and STOP stops and locks at any time.
